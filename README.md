# Affogato

An experimental Wii U emulator.

Affogato is a long-term educational emulator project written in modern C++.

## Current status

The project is currently in the initial infrastructure and architecture stage.

No Wii U hardware is emulated yet.

## Requirements

Current primary development environment:

- 64-bit host
- C++23
- GCC 14 or newer
- CMake 3.25 or newer
- Ninja 1.11 or newer

The primary Windows development toolchain currently uses MinGW-w64 GCC.
